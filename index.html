This site works out of the box — no key needed. If you're doing heavy use, you can optionally add your own key below.

Use your own API key instead (optional)
  1. Go to the Google Cloud Console — YouTube Data API page and sign in.
  2. Click Enable (create a project first if prompted).
  3. Go to Credentials → Create Credentials → API key.
  4. Copy it below.

Private playlists can only be read by the account that owns them. Sign in with the Google account that owns the playlist.

One-time setup needed (owner of this site does this once)
  1. In the same Google Cloud Credentials page, click Create Credentials → OAuth client ID.
  2. Application type: Web application.
  3. Under Authorized JavaScript origins, add your deployed site's URL (e.g. https://your-app.vercel.app) and http://localhost:3000 for testing.
  4. Copy the Client ID and paste it in the field below.
  5. You may also need to configure the OAuth consent screen (External, add yourself as a test user) if Google prompts for it.
