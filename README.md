# Manifest — Playlist Cataloger

Turn any YouTube playlist into a clean list of track titles and channels.

Paste a public, unlisted, or private playlist link and export every entry as a text file or Spotify-ready search list. Nothing is downloaded — only titles and channel names are read.

**How it helps you:** Easily transfer songs from YouTube playlists to Spotify or other services, or keep a readable backup of what is in a playlist.

**Live site:** https://playlist-manifest.vercel.app
